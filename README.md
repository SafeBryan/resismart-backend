# ResiSmart Backend

[![Backend CI](https://github.com/SafeBryan/resismart-backend/actions/workflows/ci-backend.yml/badge.svg)](https://github.com/SafeBryan/resismart-backend/actions/workflows/ci-backend.yml)

API backend del proyecto **ResiSmart**, desarrollada en **Spring Boot (Java 21, Maven)**.  
Incluye configuración de **Integración Continua (CI)** con GitHub Actions para validación automática de compilación y ejecución de pruebas en cada `push` y `pull request`.

---

## 📌 Características principales

- Framework: **Spring Boot**
- Lenguaje: **Java 21**
- Construcción: **Maven Wrapper (`./mvnw`)**
- Base de datos: **PostgreSQL** (a integrar más adelante)
- CI: **GitHub Actions** (`.github/workflows/ci-backend.yml`)

---
